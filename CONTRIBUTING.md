# Research questions and corrections

We welcome reproducibility reports, questions about the implementation, and clearly documented corrections through GitHub Issues.

For a reproducibility issue, include the command you ran, Python and package versions, the relevant error message, and whether you used the archived CSV or reran the experiment. Avoid uploading credentials, personal information, or unrelated local files.

For a proposed numerical correction, identify the affected function, metric, or table and provide a small example that demonstrates the issue. Changes to formulas or statistical definitions should be discussed separately from documentation or path fixes so their effects on the reported results can be reviewed.

Please identify the commit or release used in any reproduction report. The original manuscript archive remains available through the permanent links in APPENDIX_LINKS.md.
